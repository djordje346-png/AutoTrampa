# Landing photography

AI-created photographic backgrounds derived from the owner-selected first
AutoTrampa landing mockup (2026-10-29). These are marketing illustrations,
not listings or photos of vehicles offered for exchange.

- `hero-swap.webp`: desktop hero, 1774 × 887.
- `hero-swap-mobile.webp`: crop of that hero for stacked mobile/tablet layouts.
- `drive-cta.webp`: closing conversion banner, 1942 × 809.

Editable headings, navigation, buttons and labels remain HTML. Real marketplace
listing images are supplied by the existing marketplace hook and shared card.
